# Bias Correction in Panel Models with Asymmetric Regressors and Cross-Sectional Dependence

This repository contains the complete R code and pre-computed results to
reproduce all simulations, empirical estimates, tables, and figures in the
accompanying manuscript on bias-corrected common correlated effects estimation
of asymmetric long-run relationships in heterogeneous dynamic panels.

Everything is written in base R with a small number of well-known packages.
Each script is self-contained and can be run on its own in RStudio, or the
whole package can be reproduced end to end with the master script.

---

## How to reproduce

### Option A - regenerate the figures only (fast)

The `results/` folder already contains every pre-computed output, so the
figures can be rebuilt in seconds:

1. Open RStudio and set the working directory to the `code/` folder
   (`Session > Set Working Directory > To Source File Location`).
2. Run the four figure scripts:
   - `23_figure_1_montecarlo.R`
   - `24_figure_2_montecarlo.R`
   - `25_figure_3_empirical_app1.R`
   - `26_figure_4_empirical_app2.R`

Figures are written to `../figures/`.

### Option B - reproduce everything from scratch

1. Set the working directory to `code/`.
2. Open `00_RUN_ALL.R` and source it.

The Monte Carlo block (scripts 02-19) is the slow part: it runs a 5x5 grid of
(N, T) combinations with R = 500 replications per cell for six correctors and
three model specifications. Budget several hours. A fixed seed
(`set.seed(2026)`) is used throughout so results are exactly reproducible.

## Script index

| # | Script | Purpose |
|---|--------|---------|
| 00 | `00_RUN_ALL.R` | Master script; runs everything in order |
| 02-07 | `02_mc_csardl_*` ... | Monte Carlo, CS-ARDL specification, six correctors |
| 08-13 | `08_mc_csnardl_*` ... | Monte Carlo, CS-NARDL specification, six correctors |
| 14-19 | `14_mc_fcsnardl_*` ... | Monte Carlo, FCS-NARDL specification, six correctors |
| 20 | `20_merge_montecarlo_results.R` | Merge the 18 result files into three final tables |
| 21 | `21_empirical_application_1.R` | Empirical Application 1 (resource rents and growth) |
| 22 | `22_empirical_application_2.R` | Empirical Application 2 (income and emissions) |
| 23 | `23_figure_1_montecarlo.R` | Figure 1 - comprehensive Monte Carlo results |
| 24 | `24_figure_2_montecarlo.R` | Figure 2 - model-complexity comparison and test power |
| 25 | `25_figure_3_empirical_app1.R` | Figure 3 - country-level FCS-NARDL elasticities, App 1 |
| 26 | `26_figure_4_empirical_app2.R` | Figure 4 - country-level FCS-NARDL elasticities, App 2 |

The six correctors in each Monte Carlo family are, in order:
1. CS - uncorrected common correlated effects mean group
2. RMA - recursive mean adjustment
3. HPJ - half-panel jackknife
4. TPJ - third-panel jackknife
5. BBC - bootstrap bias correction
6. CSB - cross-section bootstrap

## Data

All data are open access.

### Downloaded automatically at runtime (World Bank WDI)

Both empirical scripts pull their World Bank series through the `WDI` package
when they run, so no manual download is needed for these. Exact series codes and
indicator pages are listed in the headers of scripts 21 and 22. The series are:

- GDP per capita, constant 2015 USD (`NY.GDP.PCAP.KD`)
- Total natural resource rents, % GDP (`NY.GDP.TOTL.RT.ZS`)
- Trade openness, % GDP (`NE.TRD.GNFS.ZS`)
- FDI net inflows, % GDP (`BX.KLT.DINV.WD.GD.ZS`)
- Urban population share and trade openness (Application 2 controls)

### Must be downloaded manually (Our World in Data)

Two large OWID files are not bundled to keep the repository light. Download
them and place them in the `data/` folder before running script 22:

| File | Source page | Direct download |
|------|-------------|-----------------|
| `owid_co2_data.csv` | https://github.com/owid/co2-data | https://nyc3.digitaloceanspaces.com/owid-public/data/co2/owid-co2-data.csv |
| `owid_energy_data.csv` | https://github.com/owid/energy-data | https://nyc3.digitaloceanspaces.com/owid-public/data/energy/owid-energy-data.csv |

See `data/README_DATA.md` for the same information.

## Notes for reviewers

- Every Monte Carlo script uses `set.seed(2026)`, so the simulated results are
  exactly reproducible across machines.
- The bundled `results/` files let you verify every table and figure without
  re-running the slow Monte Carlo block.
- The empirical estimate files in `results/empirical/` (`*_estimates.rds`)
  contain the full unit-level coefficient vectors used to draw figures 3 and 4.
